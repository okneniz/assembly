# tests/

Integration tests and the project's test infrastructure. Full run of all
gates with one command from the repository root:

```bash
make tests
```

The chain: `examples` (rebuilding the test binaries) → `test` (`go test ./...`)
→ `rt-run` (round-trip over the corpus, builds the corpus itself via `rt-cli`)
→ `rt-vm` (the behavioral VM matrix). Running a specific target: `make -C
tests <target>` - all targets and their descriptions are in the
[Makefile](Makefile).

## What lives here

- `assembly_test.go` - differential gates against objdump (Mach-O + ELF);
- `hello_asm_test.go` - round-trip of the hello-asm demo + `TestHelloVM` (QEMU);
- `cmd/` - commands and wrappers used only for tests: `assembly-diff`,
  `assembly-rt`, the `objdump/` wrapper (see [cmd/README.md](cmd/README.md));
- `examples/` - test binaries and full-cycle demos (hello-world, hello-riscv,
  hello-asm);
- `vm/` - behavioral matrix scripts (`make -C tests rt-vm`);
- `corpus/` - round-trip corpus (gitignored, regenerated by `rt-cli`/`rt-run`).

## External dependencies of the full run

- **objdump** - the oracle of the differential and property tests. For RISC-V
  you need a build with that target: Apple's `/usr/bin/objdump` does not
  support it; the `cmd/objdump` wrapper tries candidates itself (homebrew
  `llvm-objdump` and others);
- **qemu-system-aarch64 / qemu-system-riscv64** - `TestHelloVM` and the
  `rt-vm` VM matrix; `rt-vm` also needs the downloaded `corpus/vm/cache`
  (kernels/minirootfs);
- **clang with the RISC-V target** - only for `make -C tests examples`
  (Apple's `/usr/bin/clang` lacks the target;
  `/opt/homebrew/opt/llvm/bin/clang` works).

Without a required tool the corresponding step fails loudly - gates must not
stay silent; simply do not run the specific targets without it.
